Windows-Cleaner-and-Optimizer

Disk space back, system integrity checked

Windows cleanup and optimisation: browser caches, temp files, recycle bin, event and IIS logs, Windows Update leftovers, plus SFC and DISM, with restore points, dry-run and granular toggles.

What it does

  • Browser caches, temp files, logs and update leftovers
  • Restore point before anything destructive
  • Dry-run, per-category toggles and detailed logs

Built with

Batchfile, PowerShell
